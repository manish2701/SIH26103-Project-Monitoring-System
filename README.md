# 🚀 SIH26103 — Project Monitoring System

A centralized **Project Monitoring and Management System** developed for **Smart India Hackathon (SIH)** to improve project tracking, progress monitoring, issue management, and transparency across multiple stakeholders.

The platform provides a structured digital workflow for monitoring projects from initiation to completion, helping teams track milestones, activities, progress, risks, and overall project health.

---

## 📌 Problem Statement

Managing large-scale projects often involves multiple teams, milestones, dependencies, and stakeholders. Traditional monitoring methods can make it difficult to:

- Track project progress in real time
- Monitor milestones and deadlines
- Identify delays and risks early
- Manage issues and dependencies
- Maintain transparency between stakeholders
- Consolidate project information in one place

This project aims to provide a **single centralized platform** for efficient and transparent project monitoring.

---

## 💡 Solution

The **Project Monitoring System** provides a unified dashboard where users can:

- 📊 Monitor overall project progress
- 🎯 Track milestones and deliverables
- 📅 Manage project timelines and activities
- ⚠️ Identify and track risks and issues
- 👥 Coordinate different stakeholders
- 📈 Visualize project performance
- 🔍 Access project information from a centralized interface
- 🔄 Follow a structured project monitoring workflow

---

## ✨ Key Features

### 📊 Project Dashboard

Provides an overview of important project metrics, progress, milestones, and current project status.

### 🎯 Milestone Tracking

Track important project milestones and monitor whether deliverables are progressing according to schedule.

### 📈 Progress Monitoring

Visualize project completion and monitor progress across different activities and stages.

### ⚠️ Risk & Issue Management

Record, monitor, and manage project risks and issues to help teams take timely corrective actions.

### 📅 Timeline & Activity Tracking

Maintain project schedules and track activities throughout the project lifecycle.

### 👥 Stakeholder Management

Support collaboration and information sharing between project stakeholders.

### 🔔 Status Monitoring

Identify projects or activities requiring attention through clear status indicators.

### 🌙 Modern Dark UI

The interface uses a professional dark-themed design focused on readability, clarity, and efficient information presentation.
